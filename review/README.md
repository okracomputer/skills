# okraPDF review materials

Files for the OpenAI Plugin Directory review of the okraPDF plugin.

- `fy2024-financial-report.pdf`: pages from the Executive Summary of the FY 2024 Financial Report of the United States Government (U.S. Department of the Treasury; a U.S. Government work in the public domain). The review test cases use this file.
- `okrapdf-codex-demo.mp4`: a walkthrough in the Codex desktop app. It shows plugin setup, Open in → okraPDF, the okraPDF viewer tab, a selected block attached to the chat, and a cited answer.
